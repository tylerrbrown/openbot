### Fixed

- New agents no longer start on a model you switched off in Providers / Models. This also applies when you create an agent from your phone or the web client. Update the server to get this fix for connected clients. Existing agents keep their models.

### Changed

- In Server Settings → Providers, choose a default model beside the default provider. New agents in the fork’s web client use the server default unless you choose another model for that agent. The model supplies the default reasoning effort.
