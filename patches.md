# Patches on `custom`

Keep `main` as an upstream mirror. Follow [the sync procedure](README-CUSTOM.md#sync-with-upstream) to rebase `custom`. A clean rebase already reapplies the commits; do not apply them twice. After each update, check these behaviors. Retire a patch if upstream provides the same behavior.

Save the area in Instructions and post the host receipt before any model turn. Do not run a welcome turn or guess a LifeOS memory lane. |

## Sidebar check after an upstream update

Keep the **Buy credits** shortcut out of the desktop sidebar. The current fork does not render it. If an upstream sync adds it, omit the credits-store action from [`WorkspacePageRail`](src/renderer/src/features/window/WorkspacePageRail.tsx). Leave account billing, provider usage indicators and media-provider credit balances available. This does not change the public web client served by OpenBot.

Check with a **new disposable profile**, not the one you use daily: an existing profile can hide a first-launch regression. Do not run `dev:seed` or `dev:reset` against your working profile to verify an update.
